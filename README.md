# ComponentCorner

A responsive React/Vite tech store demo with an interactive shopping cart.

## Features
- Product data rendered from an array with `map()`
- React `useState` stores cart items
- Add-to-cart buttons on every product
- Header cart badge updates immediately
- Remove individual cart entries
- Cart total calculated with `reduce()`
- Empty-cart conditional rendering

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
